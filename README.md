# Digital Forensics Labs

This repository contains practical laboratory exercises completed as part of my digital forensics training.

## Labs

### Lab 1A – Data Representation
Topics covered:
- Number systems
- Binary and hexadecimal conversion
- ASCII and UTF-8
- Timestamps
- Hashing
- Endianness

### Lab 1B – System and Disk Forensics
Topics covered:
- System identification
- Evidence layers
- Processes and PIDs
- Disk and partition inspection
- Sector calculations
- Boot processes
- MBR and GPT
- File systems

> All work is documented for educational and training purposes.
